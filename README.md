# Webots Robotics Tasks

This project contains 5 robotics tasks implemented in Webots for simulation and testing.

## Tasks

### 1. Colored Object Sorting
Robot detects and sorts colored objects into their correct locations.

### 2. Continuous Pick and Place
Robot continuously picks objects and places them at target positions automatically.

### 3. Hammering
Robot performs a hammering action on a target object using controlled movement.

### 4. Path Planning
Robot calculates and follows an obstacle-free path to reach a destination.

### 5. Peg in Hole
Robot aligns and inserts a peg into a hole with precise positioning.

## Software Used
- Webots
- Python / Controller Scripts

## How to Run
1. Open the project in Webots
2. Select the required world/task
3. Run the simulation

## Purpose
These tasks demonstrate robot control, automation, motion planning, and manipulation in simulation.
